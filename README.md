# AI Klub Skills

Shareable agent skills for AI Klub.

## AI Klub MCP Publishing

Install the delegated, MCP-only publishing workflow:

```bash
npx skills add SasaSlivova-IS/ai-klub-skills --skill ai-klub-mcp-publishing
```

The skill does not contain credentials or grant access. Each colleague must connect the AI Klub MCP endpoint in their own agent and finish OAuth with their own AI Klub account. Publishing is permitted only when that account has the `creator` or `admin` role.
